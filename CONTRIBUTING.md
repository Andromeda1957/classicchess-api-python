# Contributing

This public SDK receives one-way source exports from the Classic Chess private
development monorepo after its CI checks pass. Each export is a new public
commit; private repository history and commit messages are not copied.

Please open an issue or pull request here. Maintainers apply accepted changes
in the development monorepo, run the SDK checks, then export them here. Direct
edits to this repository's default branch will be replaced by the next export.

SDK source and documentation are MIT licensed. Bundled third-party build tools
retain their own notices. Chess data, biographies, photographs and book
annotations have separate attribution and reuse terms; the SDK license covers
the software, not those API resources.
